STILLWATER - WINDOWS DESKTOP EDITION

Open the portable Stillwater .exe in the release folder. It runs in its own
desktop window and includes its runtime. No Node.js installation or browser
launcher is needed to use the executable.

Read README.md for the current instructions, local data location, backup
guidance, development commands, and GitHub preparation notes.

The desktop diary is stored separately from the executable at:
%APPDATA%\Stillwater\diary\diary.sqlite

Start Stillwater.vbs / .cmd also open the built desktop executable. They
require a completed Windows build in this source folder's release folder.

Use Settings > Save full backup to keep a copy of your diary.

There is no password lock or encryption at rest. Backups are also
unencrypted. Keep regular backups in a private location outside this folder.

MATH SYMBOLS
In an entry, click Insert math in the formatting toolbar. Search or browse a category, click symbols to build an expression, then click Insert. It replaces selected text or appears at your cursor. Select text and use x² / x₂ for superscript or subscript. Symbols work offline and remain in saved entries and exports. Leave Use LaTeX-style math checked to typeset only the inserted math. For example: T(n) = aT(n/b) + O(n^d). Double-click inserted math to edit it. The math font and renderer are bundled offline.
